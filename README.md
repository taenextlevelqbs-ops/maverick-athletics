# Maverick Athletics — Sports Website

A sports-focused web presentation project with athlete/coaching imagery and a static HTML entry point.

## Project overview
This repository demonstrates a lightweight, static website approach rather than a full backend application.

## Technology
- HTML/CSS
- Static assets
- Responsive website design

## View
Open `index.html` in a browser or serve the folder with a simple local HTTP server.
